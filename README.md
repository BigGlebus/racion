# Рацион дня

Личное приложение для телефона: план продуктов на день по приёмам пищи (завтрак, обед, перекус, ужин, «в течение дня»), подсчёт ккал и БЖУ против цели.

Открыть:
- https://bigglebus.github.io/racion/ — сайт-приложение, можно «Добавить на экран „Домой“», работает без интернета. Данные — в памяти этого браузера.
- https://claude.ai/artifact/VRQhjUrPT393EyGRYa3fU6 — та же страница в Claude (видна только владельцу), данные синхронизируются между устройствами через аккаунт Claude.

Данные у этих двух вариантов раздельные.

Код: https://github.com/BigGlebus/racion (личный GitHub, как у «Звукача» и «Ещё подхода»).

## Что умеет

- Новый день начинается с базового дня из плана (~2340 ккал, ~190 г белка) или со своего шаблона.
- Итоги дня сверху: ккал против цели, Б/Ж/У с диапазонами и пометками «мало / норма / много».
- Нажать на продукт — изменить граммы (шаг, быстрые порции, ввод числа), удалить.
- Кружок слева — «съедено»; сверху появляется, сколько уже съедено.
- Около 100 продуктов в 8 категориях: мясо и птица, рыба и морепродукты, яйца и молочное, гарниры, овощи, фрукты и ягоды, перекусы, масло и соусы (внутри — подгруппы: крупы / картофель и хлеб, свежие / сухофрукты и т. п.).
- Кнопка ⇄ — замены только внутри категории продукта: сначала из плана (яйца → яйца + сыр, творог → сырники и т. д.), потом по правилу: молочное, мясо, рыба — по граммам белка; крупы — тот же сухой вес; овощи — тот же вес; остальное — по калориям. Если замена жирнее (горбуша, бедро, говядина, сыр), масло из этого приёма убирается само.
- «Добавить продукт» тоже работает по категориям: сначала выбирается категория (для перекуса сразу открываются «Перекусы», для обеда — то, чего в приёме ещё нет), потом продукт из неё.
- Меню дня (⋯): вес, «как вчера», базовый день, свой шаблон, очистить.
- Вкладка «Продукты»: справочник на 100 г и добавление своих продуктов.
- Вкладка «Цели»: калории (шаг 50), диапазоны БЖУ, среднее веса за 7 дней против прошлой недели, правила.

## Где хранятся данные

В артефакте — в личном разделе базы артефакта (`data/users/<id>/planner`, один документ со всем состоянием): одинаково на телефоне и компьютере. Плюс копия в `localStorage` браузера. Если открыть файл вне Claude — только `localStorage`.

## Файлы

- `index.html` — всё приложение, исходник (без `<!doctype>`/`<head>`: их добавляет публикация артефакта).
- `tools/build.mjs` — сборка сайта в `docs/`: полная страница, `sw.js` (офлайн-кэш), манифест, иконки. Версия (дата + хэш исходника) ставится сама и видна внизу вкладки «Цели».
- `docs/` — то, что отдаёт GitHub Pages (ветка `main`, папка `/docs`).

## Как выложить обновление

```bash
node tools/build.mjs
git add -A && git commit -m "..." && git push
```

И артефакт — публикацией `index.html` по той же ссылке.
- `_local.html` — локальная копия с заголовком страницы для проверки в браузере (в git не идёт). Собрать заново:

```bash
{ printf '<!doctype html><html><head><meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1,viewport-fit=cover"></head><body>'; cat index.html; printf '</body></html>'; } > _local.html
python -m http.server 5611
```

Значения продуктов приблизительные (из плана питания); бедро куриное и мука добавлены по справочным данным.
