# Рацион дня

Личное приложение для телефона. Главное — **генерация плана питания на день** под мои цели (2400 ккал, белок 180–190 г). Факт съеденного веду в FatSecret и переношу сюда вручную — итог по каждому приёму.

Открыть:
- https://bigglebus.github.io/racion/ — сайт-приложение, можно «Добавить на экран „Домой“», работает без интернета. Данные — в памяти этого браузера.
- https://claude.ai/artifact/VRQhjUrPT393EyGRYa3fU6 — та же страница в Claude (видна только владельцу), данные синхронизируются между устройствами через аккаунт Claude.

Данные у этих двух вариантов раздельные.

Код: https://github.com/BigGlebus/racion (личный GitHub, как у «Звукача» и «Ещё подхода»).

## Что умеет

- **Приёмы — как в FatSecret:** Завтрак, Обед, Ужин, Перекус (бывший «В течение дня» влит в «Перекус», старые дни переносятся сами).
- **Случайное меню** на каждый новый день (сегодня и дальше), шаблоны приёмов:
  - завтрак — яйца + творог/йогурт + хлеб/овсянка, или каша/блюдо к завтраку + творог/йогурт;
  - обед — мясо/рыба + гарнир + овощи + масло, или одно готовое блюдо + овощи, или суп + мясо/рыба + хлеб;
  - ужин — мясо/рыба + гарнир + овощи + масло, или готовое блюдо + овощи;
  - перекус — кисломолочное/протеин + 2 фрукта + орехи; напиток подбирается так, чтобы добрать белок дня (если обед — пельмени, будет протеин или скир).
  Порции пересчитываются равноценно (белок — по белку, крупы — по сухому весу, готовые блюда — по калориям), из 40 попыток берётся меню, которое укладывается в ккал и белок. Чаще выпадает **любимое** (♥), своё и то, чего давно не было. Жирный белок — без масла в приёме. «Другое меню» — составить заново.
- **Сводка дня:** переключатель «План / Факт». В обоих — ккал против цели и Б/Ж/У с диапазонами и пометками «мало / норма / много»; факт — сумма внесённого по приёмам («N из 4»), не внесённые Б/Ж/У показаны прочерком.
- **Приём:** продукты с отметкой «ел / не ел» (кружок), таблица «План / Факт» (ккал, Б, Ж, У); «Факт» — ввести итог приёма из FatSecret (достаточно ккал).
- **Окно продукта** (нажать на продукт): порция, ♥ в любимые, «Перенести в» другой приём, удалить.
- **Замена (⇄):** только этот продукт; советы — из той же категории (любимое, давно не было, близко по ккал), «Любой другой продукт» — все категории и поиск. Порция не выводит день за цель по калориям и не больше 2,5 обычных порций.
- **Добавить продукт:** категории + «♥ Любимые», поиск, 2 совета; порция — в пределах остатка калорий дня.
- **База ~380 продуктов и блюд** (значения на 100 г, справочные, примерные), категории: основное блюдо (мясо и птица, рыба и морепродукты, готовые блюда, супы, колбасы), гарниры и хлеб, овощи и салаты, завтраки и каши, яйца и молочное, фрукты и ягоды, перекусы и сладкое, напитки, масло и соусы. Фастфуд, колбасы, сладкое и напитки сами в меню не попадают — только если отмечены ♥ или добавлены вручную.
- **Свои продукты** («Свой продукт» во вкладке «Продукты»): категория и подгруппа (определяют место в меню), значения на 100 г, порция в граммах или штуках (вес 1 шт — ккал порции считаются сами). Собраны в «Мои».
- **Дни:** только вчера, сегодня и завтра. История хранится 14 дней — для «давно не было».
- **Цели:** калории (шаг 50), диапазоны БЖУ, правила.

## Где хранятся данные

В артефакте — в личном разделе базы артефакта (`data/users/<id>/planner`, один документ со всем состоянием, включая `fav` — любимые и `days[*].fact` — факт по приёмам): одинаково на телефоне и компьютере. Плюс копия в `localStorage` браузера. На сайте github.io — только `localStorage`.

## Файлы

- `index.html` — всё приложение, исходник (без `<!doctype>`/`<head>`: их добавляет публикация артефакта). База продуктов — строка `FOODS` в начале скрипта: одна строка на продукт, `код;название;категория;подгруппа;ккал;Б;Ж;У;порция;флаги;подсказка`.
- `tools/build.mjs` — сборка сайта в `docs/`: полная страница, `sw.js` (офлайн-кэш), манифест, иконки. Версия (дата + хэш исходника) ставится сама и видна внизу вкладки «Цели».
- `docs/` — то, что отдаёт GitHub Pages (ветка `main`, папка `/docs`).
- `_local.html` — локальная копия с заголовком страницы для проверки в браузере (в git не идёт).

## Как выложить обновление

```bash
node tools/build.mjs
git add -A && git commit -m "..." && git push
```

И артефакт — публикацией `index.html` по той же ссылке.

Локальная проверка:

```bash
{ printf '<!doctype html><html><head><meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1,viewport-fit=cover"></head><body>'; cat index.html; printf '</body></html>'; } > _local.html
python -m http.server 5611
```
