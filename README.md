# Рацион дня

Личное приложение для телефона: **разбор дневника питания из FatSecret** против моих норм (2400 ккал, белок 180–190 г, жиры 70–90 г, углеводы 220–250 г) — отклонения и что поправить. Без ИИ: рекомендации по правилам.

Открыть:
- https://bigglebus.github.io/racion/ — сайт-приложение («На экран „Домой“»). Отчёт — **по ссылке** или PDF-файлом.
- https://claude.ai/artifact/VRQhjUrPT393EyGRYa3fU6 — та же страница в Claude; там внешние адреса закрыты, поэтому отчёт — **только PDF-файлом** (Поделиться → Сохранить в «Файлы»).

Код: https://github.com/BigGlebus/racion (личный GitHub). Генератор меню (версии до 25.11.2026) — в истории git.

## Вкладки

- **Разбор** — ссылка на отчёт FatSecret (`https://foods.fatsecret.com/export/…/FoodDiary_<ггммдд>_foods.pdf`) или PDF-файл. Показывает:
  - итог дня против норм с отклонениями («мало · −93 г»);
  - таблицу по приёмам (Завтрак, Обед, Ужин, Перекус) — ккал/Б/Ж/У, недобор белка по приёму, продукты по нажатию;
  - «Что поправить» — советы по правилам с оценкой «−N г жира / +N г белка»: масло «на глаз», сладкое с жиром к чаю, сыр, орехи > 20 г, колбаса/ветчина, жарка в масле, жирные соусы, сэндвичи с ветчиной и сыром, яйца, «углеводные» блюда с малым белком; плюс «Похоже, ошибка в карточке FatSecret» (ккал не сходятся с Б/Ж/У);
  - «Что съесть / добрать до конца дня» — если приём не внесён или калорий мало: постный белок из памятки на недостающий белок, гарнир на оставшиеся ккал, итог дня после этого;
  - «Откуда жир» — 5 главных источников.
  Последние 14 разобранных дней хранятся, переключаются чипами.
- **Белок** — памятка продуктов с высоким белком (на 100 г), метка «г белка на 100 ккал» (зелёная — от 15). Можно убирать и добавлять свои, «Вернуть стандартный список». Блок «до конца дня» берёт продукты отсюда.
- **Цели** — калории (шаг 50), диапазоны БЖУ, белок по приёмам, правила.

## Как устроен разбор PDF

pdf.js (cdnjs, 3.11.174) достаёт текст с координатами; строки собираются по Y, цифры раскладываются по колонкам заголовка (Кал, Жир, Углев, Белк…) по ближайшему центру; строки приёмов — «Завтрак / Обед / Ужин / Перекус/Другое», под продуктом — граммовка, «Всего» — итог приёма, последний «Всего» — итог дня. Проверено на отчётах за 24 и 25.11.2026 (совпадение до сотых). Тестовые PDF и страница-зонд — в `_test/` (в git не идут: там личные данные).

**По ссылке из браузера отчёт не скачать:** FatSecret (CloudFront) отдаёт `Access-Control-Allow-Origin: *` только запросам без заголовка `priority`, а браузеры (Chrome, Safari) шлют его всегда — проверено 26.11.2026 перебором заголовков. Поэтому основной путь — PDF-файл; при ошибке по ссылке приложение показывает кнопку «Открыть отчёт» и подсказку «Поделиться → Сохранить в Файлы». Поэтому ссылка идёт через свой прокси на Cloudflare Workers — https://racion-proxy.speertraeger17.workers.dev/ (аккаунт пользователя, код — `tools/proxy-worker.js`: пускает только сайт bigglebus.github.io и только ссылки FatSecret `/export/`, ничего не хранит). Обновить код прокси — в панели Cloudflare: Workers & Pages → racion-proxy → Edit code → Deploy. Офлайн-кэш (`sw.js`) запросы к FatSecret не трогает.

## Данные

`localStorage` (`racion:v2`): нормы, памятка белка, последние разборы. В Claude — ещё и личный раздел базы артефакта (`data/users/<id>/racion2`).

## Файлы и выкладка

- `index.html` — исходник (без `<!doctype>`/`<head>`: их добавляет публикация артефакта).
- `tools/build.mjs` — сборка сайта в `docs/` (страница, `sw.js`, манифест, иконки; версия = дата + хэш, видна во вкладке «Цели»).

```bash
node tools/build.mjs
git add -A && git commit -m "..." && git push
```

И артефакт — публикацией `index.html` по той же ссылке.
