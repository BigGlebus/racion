# Рацион дня

Приложение для телефона: **разбор дневника питания из FatSecret** против своих норм — отклонения и что поправить. Нормы считаются по формуле из пола, возраста, роста, веса, активности и цели (или задаются вручную). Без ИИ: рекомендации по правилам. Им может пользоваться кто угодно — данные у каждого свои, на его телефоне.

Открыть:
- https://bigglebus.github.io/racion/ — сайт-приложение («На экран „Домой“»). Отчёт — **по ссылке** или PDF-файлом.
- https://claude.ai/artifact/VRQhjUrPT393EyGRYa3fU6 — та же страница в Claude; там внешние адреса закрыты, поэтому отчёт — **только PDF-файлом** (Поделиться → Сохранить в «Файлы»).

Код: https://github.com/BigGlebus/racion (личный GitHub). Генератор меню (версии до 25.11.2026) — в истории git.

## Вкладки

- **Разбор** — ссылка на отчёт FatSecret за день (`…/day/food/FoodDiary_<ггммдд>_foods.pdf`) или за неделю (`…/week/food/…`, раскладывается по дням; день с той же датой заменяется свежей версией) или PDF-файл. Показывает:
  1. **Общая сводка** — итог дня против норм; цвет — уровень отклонения: **сильный недобор** (>10% ниже) — красный, **недобор** — светло-красный, **норма** — зелёный, **перебор** (до 10%) — жёлтый, **сильный перебор** — оранжевый; рядом всегда подпись («недобор −46 г»); у калорий отклонение — от цели (2400), норма ±100.
  2. **По приёмам** — таблица с цветом каждой ячейки против нормы приёма (доля дня: завтрак 25%, обед и ужин 30%, перекус 15%; белок — 40–50 / 45–55 / 45–55 / 30–40), продукты по нажатию.
  3. **Почему так и что исправить** — карточка на каждый показатель (калории, белок, жиры, углеводы). В норме — одна строка. Вне нормы — «Почему так» (только причины, до 3 пунктов: какие приёмы перекосили, доля калорий из жира, сладкое и фрукты, источники жира по группам, мало постного белка, калории почти без белка, большие порции) и «Что исправить» (действия с эффектом: «−13 г жира», «+24 г белка», «−34 г углеводов», «−120 ккал»). Советы по продуктам — масло «на глаз», сладкое с жиром к чаю, сыр, орехи > 20 г, колбаса, жарка, соусы, сэндвичи, яйца, «углеводные» блюда с малым белком — попадают в карточку первого показателя, который вышел за норму «в плохую сторону», без повторов; белок добирается постным продуктом из памятки в недобравший приём; карточки ссылаются друг на друга («Советы по жирам ниже — −450 ккал»). Названия — без марки производителя.
  4. **Проверьте в FatSecret** — продукты, у которых ккал не сходятся с Б/Ж/У (ошибка в карточке).
  5. **Что съесть** — только если приём не внесён: постный белок из памятки, овощи, гарнир, итог дня после этого.

  Хранится до 120 разобранных дней, переключаются чипами.
- **Динамика** — калории, белок, жиры и углеводы линиями на одном графике (7 / 14 / 30 дней / все; весь день или один приём). Шкала одна — **% от нормы** (100% — середина нормы), второй оси нет. Цвета показателей: калории — индиго, белок — синий, жиры — винный, углеводы — бирюзовый (проверены на различимость, в т.ч. при дальтонизме). Кнопки над графиком: **К / Б / Ж / У — фокус** на показателе: он яркой толстой линией с полосой своей нормы и числами в днях вне нормы, остальные — бледным фоном для сравнения; **«Все»** — все линии в цвете, нормы — цветными отрезками справа. Выбор запоминается на телефоне. Точка вне нормы — в кольце цвета уровня. Касание дня — все четыре значения с уровнями и ссылка на разбор. Неполный день (не внесён завтрак, обед или ужин) — полые точки и «*», без оценки и вне средних. Ниже — таблица дней со строкой «Среднее» и средние по неделям (пн–вс) с разницей к прошлой неделе. Выбор графика — из пяти макетов (https://claude.ai/artifact/V35giWEe6x7GxAqnZby8Y7), взят вариант 2.
- **Белок** — памятка продуктов с высоким белком (на 100 г), метка «г белка на 100 ккал» (зелёная — от 15). Можно убирать и добавлять свои, «Вернуть стандартный список». Блок «до конца дня» берёт продукты отсюда.
- **Цели** — «О себе» (пол, возраст, рост, вес, активность из 5 уровней, цель: сбросить / держать / набрать и темп) → «Как посчитано»: обмен в покое по формуле Миффлина — Сан Жеора (10 × вес + 6,25 × рост − 5 × возраст + 5 у мужчин, −161 у женщин) × активность (1,2…1,9) ± темп (дефицит 10–25% или прибавка 5–15%), округление до 50 ккал, не ниже 1500 / 1200 ккал; белок 1,8 г/кг (1,6 при «держать»), жиры 0,7–0,85 г/кг (не ниже 0,6), углеводы — остаток калорий; при ИМТ > 30 белок и жиры — от веса с поправкой на лишний жир. Белок по приёмам — доля дневной нормы (25 / 28 / 28 / 19%). Пока «О себе» не заполнено, на «Разборе» — подсказка, а разбор идёт по примерным нормам. Ручная правка калорий или БЖУ выключает формулу (вернуть — «Взять эти нормы» или «Отменить»). Сохранённые до этой версии нормы считаются ручными. ## Как устроен разбор PDF

pdf.js (cdnjs, 3.11.174) достаёт текст с координатами; строки собираются по Y, цифры раскладываются по колонкам заголовка (Кал, Жир, Углев, Белк…) по ближайшему центру; строки приёмов — «Завтрак / Обед / Ужин / Перекус/Другое», под продуктом — граммовка, «Всего» — итог приёма, последний «Всего» — итог дня, если сходится с суммой приёмов (у приёма из одного продукта FatSecret свой «Всего» не печатает — раньше из-за этого итог дня считался дважды). Длинное название иногда слипается в PDF с калориями («… Глазированный 120») — число отрезается и уходит в свою колонку. Проверено на отчётах за 24 и 25.11.2026 (совпадение до сотых). Тестовые PDF и страница-зонд — в `_test/` (в git не идут: там личные данные).

**По ссылке из браузера отчёт не скачать:** FatSecret (CloudFront) отдаёт `Access-Control-Allow-Origin: *` только запросам без заголовка `priority`, а браузеры (Chrome, Safari) шлют его всегда — проверено 26.11.2026 перебором заголовков. Поэтому основной путь — PDF-файл; при ошибке по ссылке приложение показывает кнопку «Открыть отчёт» и подсказку «Поделиться → Сохранить в Файлы». Поэтому ссылка идёт через свой прокси на Cloudflare Workers — https://racion-proxy.speertraeger17.workers.dev/ (аккаунт пользователя, код — `tools/proxy-worker.js`: пускает только сайт bigglebus.github.io и только ссылки FatSecret `/export/`, ничего не хранит). Обновить код прокси — в панели Cloudflare: Workers & Pages → racion-proxy → Edit code → Deploy. Офлайн-кэш (`sw.js`) запросы к FatSecret не трогает.

## Как дать другому человеку

Просто отправить ссылку https://bigglebus.github.io/racion/ — открыть в Safari или Chrome, «На экран „Домой“», заполнить «Цели» → «О себе». Данные хранятся только на его телефоне, ваши он не видит. Ссылки на отчёты идут через тот же прокси (бесплатный лимит Cloudflare — 100 000 запросов в день). Разбор понимает русский отчёт FatSecret: в ссылке приложение само ставит `lang=ru`, а PDF-файл нужен на русском. Страница в Claude — личная, её другим не давать.

## Данные

`localStorage` (`racion:v2`): «О себе», нормы (по формуле или ручные), памятка белка, последние разборы; `racion:focus` — выбранный показатель на графике. В Claude — ещё и личный раздел базы артефакта (`data/users/<id>/racion2`).

## Файлы и выкладка

- `index.html` — исходник (без `<!doctype>`/`<head>`: их добавляет публикация артефакта).
- `tools/build.mjs` — сборка сайта в `docs/` (страница, `sw.js`, манифест, иконки; версия = дата + хэш, видна во вкладке «Цели»).

```bash
node tools/build.mjs
git add -A && git commit -m "..." && git push
```

И артефакт — публикацией `index.html` по той же ссылке.
